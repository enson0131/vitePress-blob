Token 与 Embedding：为什么 AI 能把文字变成数学？

上一篇我们学习了 ChatGPT 的基本工作流程：用户输入 → Tokenization → Transformer → 预测下一个 Token → 生成回答。

计算机只认识数字，为什么 ChatGPT 能知道「苹果」和「香蕉」在语义上比较接近？

答案就在两个核心概念里：Token 与 Embedding。

一、Token：AI 眼中的文字

模型不会直接处理字符串，而是先通过 Tokenizer 将文本转换为 Token ID。

第一步：文本分词（示意）
我是一名前端开发工程师
↓
我是一名前端开发工程师
↓
123456789234567
分词和 ID 仅为示意，不是真实 Tokenizer 输出。

为什么不直接按照汉字分词？

模型需要处理多种语言、代码和符号，例如 JavaScript、useState、console.log()、日期等。常见的 Tokenizer 使用 BPE 等策略。

Token 数量不等于字数，也不等于单词数。

二、Embedding：把文字转换成向量

Token ID 只是编号，例如「苹果 → 1024」并不能直接表达「水果」的含义。Embedding 将离散编号映射为连续向量：

苹果 → [0.82, 0.71, 0.13, ...]
香蕉 → [0.79, 0.75, 0.18, ...]
汽车 → [0.12, 0.09, 0.91, ...]

以上为教学假设。真实向量可能有数百至数千维，单个维度通常没有固定的人类可解释含义。

三、为什么向量能够表示语义？

在经过训练的语义 Embedding 空间中，相关文本往往具有较高相似度。例如「苹果」和「香蕉」可能比「苹果」和「汽车」更接近。

语义向量空间（概念示意）人为绘制的二维投影示意，不是真实 Embedding 模型的计算结果。

语义信息通常分布在多个维度中，不能简单把某个维度等同于「水果属性」。同一个词还可能有不同含义，例如「苹果」也可能指科技公司。

四、Embedding 是如何学习出来的？

Token Embedding

LLM 内部的 Token ID 到向量映射，通常随语言模型的训练一起优化。

Text Embedding

用于句子、文档语义检索，常通过对比学习等方式训练。

例如「如何使用 React 管理状态？」和「React 状态管理怎么做？」应比「广州天气如何？」更接近。

五、如何计算两个向量的相似度？

常用方法是 Cosine Similarity（余弦相似度）。

sim(A,B) = A · B‖A‖ ‖B‖

非零向量的余弦相似度范围为 -1 到 1。越接近 1，方向越一致；但这不能保证事实正确。

在 RAG 中可以用向量相似度检索相关片段，但还需要重排序、过滤和质量评估。

六、TypeScript 如何使用 Embedding？

通过 Embedding API 将文本转换为向量，示例如下：

import OpenAI from "openai";

const client = new OpenAI();

async function getEmbedding(text: string) {
  const result = await client.embeddings.create({
    model: "text-embedding-3-small",
    input: text,
  });
  return result.data[0].embedding;
}

const vector = await getEmbedding("如何使用 React 管理状态？");
console.log(vector.length); // 默认 1536 维

可以将向量保存到 PostgreSQL + pgvector、Qdrant 等数据库。查询与文档向量必须采用兼容的模型和配置。

八、Embedding 和 Transformer 的关系

LLM 内部的数据流（简化）
用户输入
↓
Tokenizer：文本 → Token ID
↓
Token Embedding：ID → 向量
↓
Transformer：上下文计算
↓
输出层：下一个 Token 概率
↓
生成回答

Embedding 提供初始表示，Transformer 结合上下文不断更新隐藏状态；还会使用位置信息、残差连接等机制。

十、学习疑问与解答

Q1：是不是不同方向的投影，就会有不同的语义？

提问日期：2026-10-15

结论：区分「向量方向」与「投影方向」。

  • 原始向量的方向可能反映语义关系，但语义分布在多个维度中。
  • 投影方向只是观察高维向量的方式，不改变原始向量。
  • 不同投影可能突出不同特征，也可能丢失信息；二维相近不一定代表高维相近。

类比：三维物体从正面和侧面看轮廓不同，但物体本身没有改变。
