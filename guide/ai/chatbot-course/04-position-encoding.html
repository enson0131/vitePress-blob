位置编码：Transformer 如何知道 Token 的顺序？

上一篇我们学习了 Transformer 与 Self-Attention。但如果模型主要计算 Token 之间的关系，它怎么知道哪个词在前、哪个词在后？

例如「小明喜欢小红」和「小红喜欢小明」包含几乎相同的词，但语义不同。关键在于 Positional Encoding（位置编码）。

一、为什么 Transformer 需要位置信息？

Attention(Q,K,V) = softmax(QKᵀ / √dₖ) V

公式本身没有显式绝对位置编号。不带位置机制的普通 Self-Attention 具有排列等变性：交换输入位置，输出也相应交换，不能凭空识别原始顺序。

小明 → 喜欢 → 小红
小红 → 喜欢 → 小明

GPT 的因果掩码本身也引入一定顺序结构，但不能完全替代专门的位置表示机制。

二、位置编码是如何工作的？

一种经典方案是将 Token Embedding 与位置向量相加：

Xᵢ = Eᵢ + Pᵢ
Token Embedding + Position Embedding
小明Token Embedding
＋
位置 0Position Embedding
↓
X0
喜欢Token Embedding
＋
位置 1Position Embedding
↓
X1
小红Token Embedding
＋
位置 2Position Embedding
↓
X2
这是经典绝对位置向量相加方案，不是所有模型的实现。

三、绝对位置编码有哪些实现方式？

3.1 可学习位置编码

定义一张可训练的位置向量表。实现简单，但固定大小的表通常不能直接覆盖未配置的位置。

位置 0 → [0.12, 0.35, ...]
位置 1 → [0.71, 0.22, ...]
位置 2 → [0.45, 0.91, ...]

3.2 正弦位置编码

PE(pos,2i) = sin(pos / 100002i/d)
PE(pos,2i+1) = cos(pos / 100002i/d)

不同维度使用不同频率的正弦、余弦波。pos 是位置，i 是维度对索引，d 是维度。

交互实验：正弦位置编码
维度 0-0.959
维度 10.284
维度 20.479
维度 30.878
维度 40.050
维度 50.999
维度 60.005
维度 71.000
蓝色是 sin，绿色是 cos。仅为 8 维示例，不保证无限长度泛化。

四、RoPE：现代大模型常见的旋转位置编码

RoPE（Rotary Position Embedding）通常作用于 Query、Key 的成对维度，对它们施加位置相关的旋转，而不是直接给 Token Embedding 加一个位置向量。

4.1 用二维向量理解旋转

R(θ) = [ cosθ　−sinθ ; sinθ　cosθ ]

旋转会改变向量方向，但保持长度。

交互实验：RoPE 二维旋转
角度：0°
长度：1.000
教学用二维单频率旋转；真实 RoPE 使用多组频率。

4.2 为什么 RoPE 能表示相对位置？

(Rₘq)ᵀ(Rₙk) = qᵀRₙ₋ₘk

旋转后 Q/K 的点积可以表示为与位置差 n−m 有关的形式。因此模型可以利用相对位置关系。

句子 A：我 喜欢 学习 AI
位置：   0   1    2   3
句子 B：昨天 我 喜欢 学习 AI
位置：     0  1   2    3   4

「喜欢」与「学习」的相对距离仍为 1。RoPE 并不保证任意长上下文的表现不变，扩展上下文通常需要训练或缩放方案。

五、位置编码与 Causal Mask 有什么区别？

机制作用
Position Encoding表示位置及相对关系
Causal Mask限制可访问的 Token
Self-Attention聚合可访问位置的信息

对于「我 → 喜欢 → 学习 → AI」中的「学习」，位置编码提供顺序信息，因果掩码屏蔽未来的 AI，Self-Attention 聚合前面的信息。

六、TypeScript 工程实践

function positionalEncoding(
  position: number,
  dimension: number
): number[] {
  if (!Number.isInteger(position) || position < 0 ||
      !Number.isInteger(dimension) || dimension <= 0 ||
      dimension % 2 !== 0) {
    throw new Error("位置必须非负，维度必须是正偶数");
  }
  return Array.from({ length: dimension }, (_, i) => {
    const frequency = Math.pow(
      10000, 2 * Math.floor(i / 2) / dimension
    );
    const angle = position / frequency;
    return i % 2 === 0 ? Math.sin(angle) : Math.cos(angle);
  });
}
console.log(positionalEncoding(0, 8));
console.log(positionalEncoding(1, 8));
console.log(positionalEncoding(10, 8));

调用现成 LLM API 通常无需手动实现位置编码。理解它有助于研究上下文窗口、长上下文扩展和模型架构差异。

七、本篇总结

概念一句话理解
位置编码向模型注入顺序信息
可学习位置向量训练得到的绝对位置表示
正弦位置编码多频率 sin/cos 函数
RoPE旋转 Q/K 体现相对位置
Causal Mask控制可访问上下文

位置编码告诉模型「在哪里」，因果掩码规定「能看哪里」，Self-Attention 决定「如何利用信息」。

学习疑问与解答

Q1：为什么 Transformer 需要位置编码？

答案：因为普通 Self-Attention 本身没有显式的 Token 顺序信息。

例如「小明喜欢小红」和「小红喜欢小明」使用相同的词，但词序和语义不同。没有位置机制的普通 Self-Attention 对输入排列具有等变性，交换输入位置，输出也会相应交换，无法凭空识别原始顺序。

位置编码用于提供顺序或位置关系信息。GPT 的因果掩码也引入一定顺序结构，但通常不能完全替代位置机制。

复习要点：位置编码告诉模型「Token 在哪里」。

Q2：经典正弦位置编码如何与 Token Embedding 结合？

答案：逐元素相加。

Xᵢ = Eᵢ + Pᵢ

Eᵢ 是 Token Embedding，Pᵢ 是位置向量，Xᵢ 是融合后的输入表示。

Token Embedding = [0.2, 0.5, 0.8, 0.1]
Position Encoding = [0.1, 0.3, 0.2, 0.4]
融合后的表示 = [0.3, 0.8, 1.0, 0.5]

这是经典绝对位置编码的方案，不是 RoPE 的实现方式。

复习要点：经典位置编码 = Token Embedding + Position Encoding。

Q3：RoPE 通常对哪些向量进行旋转？

答案：Query（Q）和 Key（K），通常不旋转 Value（V）。

Self-Attention 使用 Q、K 的点积计算匹配分数。RoPE 对 Q、K 的成对维度施加位置相关旋转，使注意力分数能够体现两个 Token 的相对位置。

RoPE 在注意力中的位置
输入隐藏状态 X
↓ 线性投影
QueryRoPE 旋转
KeyRoPE 旋转
Value通常不旋转
↓
Attention 计算
(Rₘq)ᵀ(Rₙk) = qᵀRₙ₋ₘk

其中 n−m 是相对位置差。

复习要点：RoPE 旋转 Q、K，让 Attention 感知相对位置。

Q4：Causal Mask 的作用是什么？

答案：禁止当前位置直接访问未来 Token。

例如「我 → 喜欢 → 学习 → AI」，处理「学习」时，可以关注「我」「喜欢」「学习」，但不能关注未来的「AI」。

当前 Token我喜欢学习AI
我✓×××
喜欢✓✓××
学习✓✓✓×
AI✓✓✓✓

GPT 是自回归生成模型。如果训练时可以直接看到未来的目标 Token，就可能产生信息泄漏，破坏预测目标。

复习要点：Causal Mask 决定「哪些 Token 可以看」。

四个概念的联系

机制核心作用
Token Embedding将 Token 转换为向量
Position Encoding注入位置信息
RoPE通过旋转 Q/K 体现相对位置
Causal Mask屏蔽未来位置
Self-Attention聚合上下文信息

总结：Embedding 负责表示，位置编码负责顺序，Causal Mask 负责访问限制，Self-Attention 负责上下文信息聚合。RoPE 是位置编码的一种，不是必须与传统相加式位置编码同时使用。
