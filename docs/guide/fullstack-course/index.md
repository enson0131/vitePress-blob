# 从前端到全栈：24 篇业务开发实战教程

面向已有 **Node BFF 和 Java Spring Boot 经验**的前端开发者，通过 TeamFlow 团队工单平台，逐步具备独立交付和维护业务系统的能力。

技术主线是 **React / TypeScript → Spring Boot 模块化单体 → PostgreSQL**。前期先建立完整的业务与数据保证，后半程再通过页面聚合、会话适配等具体需求引入 Node BFF，并与 Java 实现对照。

## 已发布文章

- [系列总纲与第 01 篇：从“把接口接通”到“对业务结果负责”](./01-from-bff-to-business-backend)
- [下载完整 HTML 教程](/fullstack-course/fullstack-series-01.html)

第 01 篇包含完整学习路线、24 篇课程安排、创建工单案例、职责场景练习，以及 6 道选择题的题目、答案和解析。第 02—24 篇为后续课程规划。

## 系列规划

| 篇 | 主题 | 本篇交付成果 |
|---|---|---|
| **01** | 从前端/BFF 走向完整业务交付 | 创建工单的职责、规则、失败路径与验收清单 |
| **02** | 跑通第一条真实业务链路 | React → Spring Boot → PostgreSQL 的可运行功能 |
| **03** | API 契约、校验与错误处理 | 稳定的请求、响应、状态码和错误结构 |
| **04** | 业务建模与关系建模 | 用户、团队、成员、项目、工单的数据模型 |
| **05** | SQL、关联查询与数据库迁移 | 可重复建库、升级、初始化和查询 |
| **06** | Spring Boot 的业务代码组织 | 按业务模块组织 Controller、Service、Repository |
| **07** | 事务与业务一致性 | 工单和审计记录共同提交、共同回滚 |
| **08** | 并发、幂等与状态转换 | 两人同时编辑、超时重试和非法状态变更的处理 |
| **09** | 身份认证与登录态 | 接入身份系统，理解会话与令牌生命周期 |
| **10** | 授权、RBAC 与租户隔离 | 资源级权限判断和全链路租户作用域 |
| **11** | Web 安全与输入边界 | CSRF、XSS、注入、CORS 在项目中的处理 |
| **12** | 稳定的前后端交互 | 加载、取消、重试、乐观更新和冲突恢复 |
| **13** | 有意义的自动化测试 | 真实数据库、权限拒绝、事务回滚和关键并发测试 |
| **14** | SQL 性能、索引与分页 | 读执行计划、定位慢查询、选择合适分页方式 |
| **15** | Redis 缓存与一致性 | 缓存一个适合的查询，定义失效与陈旧容忍度 |
| **16** | 异步任务、Outbox 与可靠重试 | 持久化任务、重试、失败状态和重复消费处理 |
| **17** | 文件上传与批量导入导出 | 上传权限、逐行校验、错误报告和受控下载 |
| **18** | Node BFF 的合理应用 | 聚合工单概览；对照 Node 与 Java 的用例组织 |
| **19** | 日志、指标与链路追踪 | 从页面报错追到服务、SQL 或后台任务 |
| **20** | 容器、配置与应用生命周期 | 可复现启动、健康检查、配置分离和正常退出 |
| **21** | 反向代理、域名与 HTTPS | 完整访问链路，以及 Cookie、代理和跨域排障 |
| **22** | CI/CD 与数据库变更 | 构建、校验、发布和向前兼容的数据库升级 |
| **23** | 压测、备份恢复与故障处理 | 一次有目标的压测和一次真实恢复演练 |
| **24** | 项目验收与全栈能力展示 | 可运行项目、设计说明、运行手册和成果表达 |

每篇围绕具体业务问题，包含概念与前端经验的对应、工程案例、代码或数据模型、互动练习、自测题及解析，以及课后实践和验收条件。
