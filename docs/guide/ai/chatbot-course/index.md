## 原课程大纲：六个阶段

课程目标是结合底层原理与工程开发，逐步使用 React、TypeScript 和 Node.js 构建聊天机器人。原始大纲确定了以下阶段与篇数范围，并没有给出全部 40 篇的逐篇标题。

| 阶段 | 篇数 | 主题 |
| --- | --- | --- |
| 第一阶段：AI 与大模型基础 | 01–07 | LLM、Token、Embedding、Transformer、Attention、训练、推理 |
| 第二阶段：聊天机器人核心原理 | 08–13 | Prompt、Messages、上下文窗口、多轮对话、Temperature、幻觉 |
| 第三阶段：聊天机器人工程开发 | 14–20 | React、Node.js、SSE、流式输出、消息持久化、错误恢复、架构设计 |
| 第四阶段：RAG 与知识库 | 21–27 | 文档切分、Embedding、向量数据库、检索、重排序、引用溯源、质量评估 |
| 第五阶段：Agent 与高级能力 | 28–33 | Function Calling、MCP、工具调用、长期记忆、任务规划、多智能体 |
| 第六阶段：生产级工程实践 | 34–40 | 安全、权限、性能、成本、监控、自动化测试、系统设计 |

学完第三阶段，应能开发支持流式输出、多轮对话和历史记录的聊天机器人；后续阶段继续补充知识库、工具执行与生产运行能力。

这些文章形成了三条相互衔接的知识线：

- **模型原理：** 01 总览 → 02 文本表示 → 03 上下文计算 → 04 位置信息 → 05 训练 → 06 推理 → 07 能力边界。
- **对话输入与输出：** 08 组织角色、指令和示例 → 09 选择并管理历史 → 10 持久化与检索记忆 → 11 按预算组装并验证上下文 → 12 校验和消费响应 → 13 核对结论与证据。
- **工程预习：** 01 展示整体架构，06 展示流式链路，08 展示请求与校验，09 展示会话与存储。第三阶段将把这些局部示例整合为可运行的应用。

## 每篇教程的发布验收标准

- 每篇标题上方统一展示绿色篇数进度标签、所属阶段与预计阅读时间。篇数与阶段由课程文件名自动识别；新增教程须在 frontmatter 中填写 `readingTime`（单位：分钟，例如 `readingTime: "12–15"`），由主题统一渲染信息栏。
- 正文、公式、SVG、TypeScript 代码、交互实验与原始 ChatGPT 教程逐项核对，不得随意压缩或删减。
- **每篇至少 3 道交互式选择题**，每题包含选项、正确答案和解析；必须支持提交评分及重新作答。
- 维护「学习疑问与解答」，将学习过程中提出的问题归档到对应章节。
- Vue 模板内展示源码时必须对 `<`、`&` 等字符进行 HTML 转义，或使用安全的代码渲染组件。
- GitHub PR 构建通过后才能合并；合并后再次确认 GitHub Pages 部署结果，并检查桌面、移动端和交互功能。
- 构建通过不代表视觉 1:1：应以原始 ChatGPT 版本为基准检查，无法完全复现的差异必须明确记录。
